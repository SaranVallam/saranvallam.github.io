# Saran Kumar Vallamsetti — Data Engineer Portfolio

A responsive, static portfolio website with a reusable professional portfolio design system, a data-pipeline visual language, accessible semantic HTML, mobile navigation, theme support, responsive cards, and lightweight JavaScript for navigation, scroll reveal, and form feedback.

## Run locally

Open `index.html` in a browser, or run a local server from this folder:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Personalize

- Add an email link in the contact section when you want to publish your email address.
- Add a PDF copy of your resume and link it from a new “Download Resume” button.
- Replace or expand the GitHub section after confirming which repositories should be featured.
- Add a profile photo under `assets/` only if desired.
- Reuse the CSS variables at the top of `style.css` to adapt the palette, spacing, radius, and content width for another professional portfolio.

## Deploy

This is a static site and can be deployed using GitHub Pages, Netlify, or Vercel. Upload the project folder or connect its repository, using `index.html` as the entry page.

## Content note

Portfolio content is based on the attached resume. LinkedIn and GitHub pages were not available for content extraction during generation, so the profile links are included without inventing repository or profile details.
